# Fase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every known Phase 1 defect of PENDIENTES.md: the database no longer depends on the start directory, the API answers 4xx where it gave 500, the ledger totals cover the whole period, deleted clients and articles can be restored, and the front's small data and connection defects are gone.

**Architecture:** Mostly local fixes in existing code. New API surface: `GET /api/invoices/totals`, `POST /api/{clients,articles}/{id}/restore`, a `deleted` list filter, an `invoiceStatus` delivery note filter, and a few response fields (`deletedAt`, `clientDeleted`, `vatType`/`surchargeType`, `mailPasswordUnreadable`). Each API change ships with its front consumer in the same task.

**Tech Stack:** Spring Boot 3.5 + Java 25 (`JAVA_HOME=C:\Program Files\Java\jdk-25.0.3`), JPA on SQLite, MapStruct; SvelteKit, Svelte 5 runes, Tailwind 4 tokens, Vitest 4 browser mode, Playwright e2e on the packaged jar (port 18080).

**Spec:** `docs/superpowers/specs/2026-11-03-fase-1-design.md`

## Review Focus

1. A database URL whose folder does not exist (first start on a new machine) must start cleanly, not fail in Flyway — Task 1 `createsTheMissingFolder`.
2. Restoring a client whose code a live client now has must say so, never create a second live client with that code — Task 6 `restoreRefusesATakenCode`, Task 7 e2e.
3. Ledger totals must equal the sum of all invoices of the period, also past 2000, and must be for the dates shown, not older ones — Task 3 `totalsCoverTheWholePeriod`, `totals of an older load are dropped`.
4. Changing the client of a note must never save the previous client's offered prices — Task 9 `typing a client empties the offered prices`.
5. A lost connection while printing or while a dialog is open must end on the connection screen and, once back, with the cursor where work continues — Task 8 tests.
