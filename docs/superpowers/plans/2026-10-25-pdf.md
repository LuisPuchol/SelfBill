# PDF de albaranes y facturas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the mock PDF with the real invoice, plain delivery note and valued delivery note (old program's look, same layout for both series), and let the owner upload the logo from Ajustes.

**Architecture:** On issue, the invoice also freezes the owner's fiscal data and the client's code. `PdfService` keeps its two public methods; inside, a pure builder turns an invoice or a delivery note into a `PrintedDocument` of display strings (where each datum comes from follows spec §4.2), a Thymeleaf template renders it to well-formed XHTML, and OpenHTMLtoPDF turns that into an A4 PDF with the header repeated on every page. The front only gains the logo block in `/settings/profile`.

**Tech Stack:** Spring Boot 3.5.7 + Java 25 (`JAVA_HOME=C:\Program Files\Java\jdk-25.0.3`), JPA, Flyway, SQLite; Thymeleaf (standalone engine), OpenHTMLtoPDF 1.1.87 (PDFBox 3.0.7); SvelteKit, Svelte 5 runes, Vitest 4 browser mode, Playwright e2e on the packaged jar (port 18080).

**Spec:** `docs/superpowers/specs/2026-10-25-pdf-design.md`

## Global Constraints

- Work on `main` (user's decision); implementers commit their own task on `main` with the Step-5 message plus a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never push.
- API paths relative to `selfbill-api/src/` (`.../` = `java/com/luispuchol/selfbill/selfbill_api/`); front paths relative to `front/`. Run API tests from `selfbill-api/` with `./mvnw -q test` (focused: `-Dtest=...`).
- New dependencies, exactly: `io.github.openhtmltopdf:openhtmltopdf-pdfbox:1.1.87` and `org.thymeleaf:thymeleaf` (version managed by Spring Boot). Not `spring-boot-starter-thymeleaf`, no font files: the PDF uses the standard Helvetica / Helvetica-Bold (WinAnsi covers ñ, tildes, ç, ·, €).
- Printed copy, verbatim (Spanish): box title `Factura 3852` / `Factura S-12` / `Albarán 31397`, `Fecha 31/05/2026`, `Cliente: 41 SON TERMENS GRAN CHEF SL`, `CIF/NIF: B07688310`, issuer line `ADELINA DELGADO TORRES · NIF X1422821H`, `Página 1/5`; columns `Código`, `Concepto`, `Trazabilidad`, `Cantidad`, `Precio`, `Importe`; section heading `Albarán 31397 de 02/05/2026`; totals `Base imponible`, `% IVA`, `Cuota IVA`, `% Recargo`, `Cuota recargo`, `Total`; plain note `Total 1.234,56 €`; valued note legend `Documento sin valor fiscal. No válido como factura.`
- Numbers: two decimals, `.` thousands, `,` decimals (`1.234,56`, `-2,00`); `€` (after a space) only on the final total. Dates `dd/MM/yyyy`.
- Front copy, verbatim: `Logo`, `Sin logo`, `Cambiar logo…`, `Logo guardado`, `Guarda primero los datos del titular para poder subir el logo.`, `El logotipo no puede pasar de 2 MB.` Inside `src/lib` relative imports; API texts only through `errorMessages`/`showError`.
- Never start, stop or bind anything on port 8080 and never touch the user's `selfbill.db`/`~/.selfbill/secret.key`; temp APIs on another port with temp DB + key (see `front/e2e/serve-jar.mjs`). No python. Use the `codegraph_explore` MCP tool before grep/Read.
- e2e: `npm run test:e2e` only while nothing listens on 8080; otherwise `npm run build`, `./mvnw -q package -DskipTests` (no clean), `npx playwright test`.

## Review Focus

1. A month-long invoice (4–5 sheets) keeps header, column titles and "Página n/m" on every sheet, never splits a row and never strands an "Albarán … de …" heading at the foot of a sheet — Task 3 `longDocumentRepeatsHeaderOnEveryPage` + the visual check.
2. Reprinting an invoice, or a delivery note of an issued invoice, after editing the client, the profile or an article prints what was delivered — Task 2 `noteInIssuedInvoiceUsesTheInvoiceCopy`, Task 3 `reprintAfterEditsKeepsTheCopy`.
3. Names with ñ, tildes, ç, ·, € or `&`, `<` print as typed, never as `#`, blanks or markup — Task 3 `spanishCharacters`, `escapesMarkup`.
4. Emailing a document still works now that the PDF reads lines, articles and client lazily — Task 3 `emailAttachesTheRealPdf`.
5. A very wide or very tall logo stays inside its 80 × 30 mm and does not push the client box or the table onto another sheet — Task 3 `oddLogosStayInTheirBox`.
