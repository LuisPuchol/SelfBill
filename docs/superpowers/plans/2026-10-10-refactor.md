# Segunda pasada de refactorización: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar `selfbill-api` sin comentarios superfluos, organizado en módulos de negocio verificados por Spring Modulith y usando las piezas idiomáticas de Spring Boot, sin cambiar su comportamiento.

**Architecture:** Paquetes por módulo (`catalog`, `billing`, `settings`, `mail`, `shared`) con dependencias en un solo sentido, comprobadas por `ApplicationModules.verify()`. Catálogo avisa a facturación con un evento de Spring. DTOs como records. Entidades sobre un `@MappedSuperclass`. Validación integrada de Spring MVC 6.1. Metamodelo JPA en las specifications.

**Tech Stack:** Java 25, Spring Boot 3.5.7 (Spring 6.2.12), Hibernate 6.6.33, SQLite + Flyway, MapStruct 1.6.3, Lombok 1.18.42, Spring Modulith 1.4.13, springdoc 2.8.13.

**Spec:** [docs/superpowers/specs/2026-10-10-refactor-design.md](../specs/2026-10-10-refactor-design.md)
